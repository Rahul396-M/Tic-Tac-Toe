# 🎮 Tic-Tac-Toe

A simple Tic-Tac-Toe game built using HTML, CSS, and JavaScript.

## 📌 About

This project is a basic implementation of the classic Tic-Tac-Toe game. 
Two players can play against each other by taking turns placing X and O on the board.

## ✨ Features

- 🎮 Two-player gameplay
- ❌ X and ⭕ O turns
- 🏆 Automatic winner detection
- 🤝 Draw detection
- 🔄 Restart / reset game
- 📱 Simple and responsive interface

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
